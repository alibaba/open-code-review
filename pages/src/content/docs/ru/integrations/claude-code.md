Установите команду из комплекта, чтобы OCR выполнял весь процесс внутри
[Claude Code](https://docs.anthropic.com/en/docs/claude-code): проверял diff,
классифицировал замечания и автоматически применял полезные исправления.

## Что поставляется в репозитории

В репозитории находится плагин Claude Code в каталоге
[`plugins/open-code-review/claude-code/`](https://github.com/alibaba/open-code-review/tree/main/plugins/open-code-review/claude-code).
Сам промпт команды расположен в
[`plugins/open-code-review/claude-code/commands/review.md`](https://github.com/alibaba/open-code-review/blob/main/plugins/open-code-review/claude-code/commands/review.md)
и является источником истины для описанного ниже процесса.

## Установка

### Вариант 1: маркетплейс плагинов (рекомендуется)

Выполните эти две команды **внутри Claude Code**:

```bash
/plugin marketplace add alibaba/open-code-review
/plugin install open-code-review@open-code-review
```

Они регистрируют slash-команду `/open-code-review:review`, которую можно
обновлять через `/plugin`.

### Вариант 2: непосредственное копирование файла команды

Чтобы не использовать маркетплейс плагинов, поместите файл команды прямо в
`.claude/commands/`. Она будет зарегистрирована как `/open-code-review` (без
суффикса `:review`).

**На уровне проекта** (закоммитьте вместе с репозиторием, чтобы команда была
доступна всей команде):

```bash
mkdir -p .claude/commands
curl -o .claude/commands/open-code-review.md \
  https://raw.githubusercontent.com/alibaba/open-code-review/main/plugins/open-code-review/claude-code/commands/review.md
```

**На уровне пользователя** (доступна в каждом проекте на компьютере):

```bash
mkdir -p ~/.claude/commands
curl -o ~/.claude/commands/open-code-review.md \
  https://raw.githubusercontent.com/alibaba/open-code-review/main/plugins/open-code-review/claude-code/commands/review.md
```

### Другие агенты с поддержкой команд

Файл команды — это обычный Markdown с одним полем frontmatter; в нём нет
ничего специфичного для Claude Code. Если агент поддерживает похожее соглашение
о **командах** (промпты Markdown загружаются из каталога как вызываемые
команды), используйте описанный выше способ с копированием файла: поместите
`open-code-review.md` в каталог, из которого агент читает команды, и вызовите
его принятым в агенте способом. Тело промпта не зависит от агента: оно лишь
указывает модели, какие флаги `ocr` выбрать и как классифицировать вывод.

> **Совет:** если вы не хотите самостоятельно настраивать LLM, попробуйте
> [режим делегирования](../delegate/). Он позволяет основному агенту (Claude
> Code) предоставить модель, поэтому отдельная настройка LLM не требуется.

## Использование

Вызовите команду по имени внутри Claude Code. Используйте
`/open-code-review:review`, если установили её через маркетплейс плагинов, или
`/open-code-review`, если скопировали файл напрямую:

```
/open-code-review:review
/open-code-review:review review this PR against main
/open-code-review:review focus on race conditions in commit abc123
```

Промпт разбирает запрос и выбирает подходящие флаги `ocr review`: без
аргументов — режим рабочей области (индексированные, неиндексированные и
неотслеживаемые изменения), упоминание коммита — `--commit`, упоминание
диапазона веток — `--from` / `--to`. Флаги OCR также можно передавать напрямую
(например, `/open-code-review:review --commit abc123` или
`--from main --to feature`).

## Что делает команда

Промпт команды короткий и состоит из трёх шагов:

1. **Запуск ревью.** Выполнить `ocr review --audience agent` с флагами,
   определёнными из запроса (и необязательным `--background`, если был описан
   контекст требований). Вывод перехватывается с тайм-аутом 5 минут.
2. **Фильтрация и оценка.** Присвоить каждому комментарию уровень **High** /
   **Medium** / **Low**. Комментарии с низкой уверенностью (вероятные ложные
   срабатывания, придирки, недостаток контекста) незаметно отбрасываются;
   остальные отображаются.
3. **Исправление.** Автоматически применить полезные исправления для пунктов
   High/Medium. В отличие от [навыка агента](../agent-skill/), эта команда
   **по умолчанию исправляет автоматически**: она предназначена для процесса
   «проверь и приведи в порядок», а не «покажи мне diff».

Чтобы команда запрашивала разрешение перед изменением кода или использовала
более строгие правила классификации, отредактируйте локальную копию промпта.
Claude Code перечитывает команды при каждом вызове, поэтому перезапуск не
требуется.
